# TalkToWalk

**Text-guided visual navigation of a humanoid robot**

[![TalkToWalk project page](https://davidmonis.github.io/talk-to-walk/assets/og-image.png)](https://davidmonis.github.io/talk-to-walk/)

Bachelor's thesis at Comenius University Bratislava. The goal is to fine-tune a vision-language-action (VLA) model, such as NVIDIA GR00T N1, so that a Unitree G1 humanoid can walk a route described in plain words (*"go straight, and at the next junction turn right"*) through a real building, guided by its camera and the text alone, without collisions. LiDAR and human feedback are used during fine-tuning.

**Project page:** [English](https://davidmonis.github.io/talk-to-walk/) | [Slovensky](https://davidmonis.github.io/talk-to-walk/sk.html)

**Status:** work in progress (planning phase). Code, data and models will be published in this repository as the thesis progresses.
